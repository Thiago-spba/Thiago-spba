## 🎯 Sobre o Projeto

O **Diário do Professor** é uma ferramenta desenvolvida para facilitar o cotidiano do docente em sala de aula. O app permite organizar turmas, gerenciar listas de estudantes, computar notas de avaliações, calcular médias e exportar relatórios prontos para impressão ou compartilhamento em formatos **PDF** e **Excel**.

Por ser um **PWA (Progressive Web App)**, pode ser instalado diretamente no celular ou desktop, funcionando com alta performance e suporte a cache offline.

---

## ✨ Funcionalidades

- [x] 🏫 **Gestão de Turmas:** Cadastro, listagem e seleção de turmas ativas.
- [x] 👨‍🎓 **Controle de Alunos:** Organização de chamadas e listagens nominais.
- [x] 📊 **Planilha de Lançamento de Notas:** Interface simplificada para preenchimento ágil de notas por turma.
- [x] 📄 **Exportação em PDF:** Emissão de relatórios consolidados formatados via `jsPDF`.
- [x] 📑 **Integração com Excel (`.xlsx`):** Importação e exportação de planilhas de dados.
- [x] 📱 **Instalação PWA:** Funciona como app nativo no celular e computador.
- [x] 🌓 **Dark Mode:** Alternância entre tema claro e escuro.
